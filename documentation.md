# Issue Tracking System

## Description
This system allows users to create, assign, view, and manage software issues.

## Features
-Create issues
-Assign issues
-View all issues
-View single issue
-Edit issues

## Data Storage
We use localStorage to save:
-People
-Projects
-Issues

## How to Run
Open index.html in a browser.
